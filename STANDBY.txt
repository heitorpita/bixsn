PENDENTE — TESTES AO VIVO (o mais importante; precisa de snmpd via sudo)
-------------------------------------------------------------------------------
Subir um snmpd local (v2c community RW + um usuário v3 USM conhecido) e rodar:

    sudo apt-get install -y snmpd
    # v2c: rocommunity public / rwcommunity private  em /etc/snmp/snmpd.conf
    # v3:  net-snmp-create-v3-user -ro -A <authpass> -a SHA <usuario>
    sudo systemctl restart snmpd

    bixsn -r 127.0.0.1 127.0.0.1                      # v2c community (RO)
    bixsn -r 127.0.0.1 --test-write 127.0.0.1         # confirmar RW -> CRITICAL
    bixsn --version v3 -r 127.0.0.1 127.0.0.1         # enum usuário USM
    bixsn --version v3 --v3-auth-brute -r 127.0.0.1 127.0.0.1  # brute de senha
